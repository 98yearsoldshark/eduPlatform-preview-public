# ChatGPT-Next-Web 项目结构概览

ChatGPT-Next-Web 是一个基于 Next.js 框架的前后端融合项目，提供了完整的 AI 聊天功能。本文档提供了项目的高级结构概览，帮助您理解项目的组织方式和主要模块。

## 核心目录结构

```
ChatGPT-Next-Web/
├── app/                       # 主要应用代码
│   ├── api/                   # API 路由和后端功能
│   ├── client/                # 前端 API 客户端
│   ├── components/            # React 组件
│   ├── config/                # 配置管理
│   ├── icons/                 # SVG 图标
│   ├── locales/               # 国际化文本
│   ├── masks/                 # 预设面具（角色）
│   ├── mcp/                   # MCP (Model Context Protocol) 功能
│   ├── store/                 # 状态管理
│   ├── styles/                # 样式文件
│   ├── utils/                 # 工具函数
│   ├── command.ts             # 命令处理
│   ├── constant.ts            # 常量定义
│   ├── layout.tsx             # 页面布局
│   ├── page.tsx               # 主页面
│   └── utils.ts               # 通用工具
├── public/                    # 静态资源
├── scripts/                   # 脚本文件
├── docs/                      # 文档
└── ... (其他配置文件)
```

## 主要模块说明

### 大型模块 (2000+ 行代码)

项目中有几个核心大型模块，它们构成了应用的主要功能：

1. **chat.tsx** (2172 行) - `/app/components/chat.tsx`
   - 聊天界面的核心组件
   - 处理消息渲染、发送、接收、历史记录等
   - 包含多种子组件和交互逻辑

2. **settings.tsx** (1918 行) - `/app/components/settings.tsx`
   - 应用设置界面
   - 处理用户配置、模型选择、API密钥配置等

3. **utils/chat.ts** (668 行) - `/app/utils/chat.ts`
   - 聊天相关的工具函数
   - 处理消息格式化、流式响应等

### 重要的小型模块

1. **API 客户端** - `/app/client/api.ts`
   - 负责与各种 LLM 服务通信
   - 支持多种模型提供商 (OpenAI, Anthropic, 百度, 腾讯等)

2. **状态管理** - `/app/store/`
   - 使用 Zustand 进行状态管理
   - 主要文件包括:
     - chat.ts (聊天状态)
     - config.ts (配置状态)
     - mask.ts (面具/角色状态)
     - access.ts (访问控制)

3. **Markdown 渲染** - `/app/components/markdown.tsx`
   - 负责渲染 AI 回复中的富文本内容
   - 支持代码高亮、数学公式、图表等

4. **国际化** - `/app/locales/`
   - 支持多语言
   - 包括中文、英文、日文等多种语言

5. **平台适配** - `/app/client/platforms/`
   - 支持多种 AI 服务提供商
   - 每个提供商有独立的适配实现

## 技术栈

- **前端框架**: Next.js (React)
- **状态管理**: Zustand
- **样式**: SCSS Modules
- **API通信**: Fetch API, EventSource
- **国际化**: 自定义国际化实现
- **构建工具**: Webpack (Next.js内置)

## 关键功能模块

1. **聊天核心功能** - 消息发送、接收、流式响应处理
2. **面具系统** - 预设角色和提示词管理
3. **多模型支持** - 兼容多种AI模型 (GPT-3.5, GPT-4, Claude等)
4. **设置管理** - 用户偏好和API配置
5. **历史会话** - 会话持久化和管理
6. **导出功能** - 导出聊天记录为多种格式
7. **MCP功能** - Model Context Protocol 相关功能

本文档提供了项目的高级概览，更详细的模块说明请参考各个模块的详细文档。
