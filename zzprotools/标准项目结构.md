# 📁 标准大型前后端分离项目目录结构（React + TSX 前端）

这是一个典型的前后端分离大型项目目录结构示例，适合使用 React + TypeScript 构建前端，后端可灵活替换（Node.js、Python Flask、Django、Go、Java 等）。

---

## 🧩 顶层目录结构
```
my-project/
├── backend/                # 后端服务目录
├── frontend/               # 前端 React 项目
├── docs/                   # 项目文档、API 说明
├── scripts/                # 部署、构建、迁移等脚本
├── .env                    # 根级环境变量
├── docker-compose.yml      # Docker 多服务编排
└── README.md               # 项目说明
```

---

## 💡 frontend/（React + TypeScript 项目结构）
```
frontend/
├── public/                 # 静态资源（favicon、index.html 等）
├── src/
│   ├── assets/             # 图片、图标、字体等静态资源
│   ├── components/         # 通用 UI 组件（Button、Modal）
│   ├── features/           # 各功能模块（如 auth、posts）
│   ├── hooks/              # 自定义 Hook
│   ├── layouts/            # 页面布局（如后台管理框架）
│   ├── pages/              # 页面级组件（路由页面）
│   ├── routes/             # 路由配置（如 React Router）
│   ├── services/           # API 请求封装（Axios）
│   ├── store/              # 全局状态管理（Redux、Zustand）
│   ├── types/              # 类型定义（TypeScript interfaces）
│   ├── utils/              # 工具函数（时间格式化、加密等）
│   ├── App.tsx             # 应用主组件
│   ├── main.tsx            # 应用入口
│   └── index.css           # 全局样式
├── .env                   # 环境变量（REACT_APP_）
├── tsconfig.json          # TypeScript 配置
├── vite.config.ts / webpack.config.js
└── package.json
```

---

## 💻 backend/（Node.js Express 示例）
```
backend/
├── src/
│   ├── config/             # 配置文件（数据库连接、常量）
│   ├── controllers/        # 控制器（处理路由请求）
│   ├── middlewares/        # 中间件（如认证、错误处理）
│   ├── models/             # 数据模型（ORM，如 Sequelize）
│   ├── routes/             # 路由定义
│   ├── services/           # 核心业务逻辑
│   ├── utils/              # 工具函数
│   ├── app.ts              # 应用主入口
│   └── server.ts           # 启动服务器
├── .env
├── tsconfig.json
├── package.json
└── prisma/ / migrations/   # 如果使用 Prisma 或数据库迁移工具
```

---

## 📄 docs/
```
docs/
├── api-spec.md             # 接口文档
├── db-schema.md            # 数据库结构说明
└── deployment-guide.md     # 部署说明
```

---

## 🚀 推荐工具/框架
- **前端**：React + TypeScript + Vite + TailwindCSS
- **路由**：React Router DOM v6
- **状态管理**：Zustand / Redux Toolkit / Jotai
- **请求库**：Axios / React Query
- **后端**：Express + TypeScript / Fastify / NestJS / Flask / Django
- **数据库**：PostgreSQL / MySQL / MongoDB
- **ORM**：Prisma / Sequelize / TypeORM
- **部署**：Docker + Nginx + CI/CD（GitHub Actions / Vercel / Railway）
