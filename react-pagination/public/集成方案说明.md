# ChatGPT-Next-Web 项目集成方案

本文档简要说明如何将 ChatGPT-Next-Web 项目集成到现有的 React+TypeScript+Vite 项目中。

## 集成方案概述

采用 iframe 嵌入方式集成，通过代理转发请求，保留 ChatGPT-Next-Web 完整功能，同时提供简单的UI集成。

## 项目结构

```
您的主项目/
├── src/                     # 主项目源代码
│   ├── components/
│   │   ├── ChatFrame.tsx    # iframe包装组件
│   │   └── ChatFrame.css    # 样式文件
├── chatgpt-next-web/        # ChatGPT-Next-Web 子项目(完整)
│   ├── app/
│   ├── public/
│   └── next.config.mjs      # 修改过的配置文件
├── package.json             # 合并后的依赖和脚本
└── vite.config.ts           # 添加代理配置
```

## 主要修改内容

### 1. package.json 整合

- 合并两个项目的依赖
- 添加带前缀的脚本命令（chat:dev, chat:build 等）
- 修改 React 版本以确保兼容性

### 2. Next.js 配置修改

修改 `chatgpt-next-web/next.config.mjs`：

```javascript
const nextConfig = {
  // 设置basePath为/chat，这样所有URL都会以/chat开头
  basePath: '/chat',
  // 设置assetPrefix，这样所有静态资源都会从/chat加载
  assetPrefix: '/chat',
  // 配置头信息允许在iframe中加载
  async headers() {
    return [
      {
        source: '/(.*)',
        headers: [
          {
            key: 'X-Frame-Options',
            value: 'SAMEORIGIN',
          },
        ],
      },
    ];
  },
};
```

### 4. Vite 代理配置

在 `vite.config.ts` 中添加代理配置：

```typescript
export default defineConfig({
  plugins: [react()],
  server: {
    port: 3000,
    proxy: {
      // 将/chat路径代理到ChatGPT-Next-Web应用
      '/chat': {
        target: 'http://localhost:5011',
        changeOrigin: true,
      }
    }
  }
});
```

## 使用方式

1. 在主应用中使用 ChatFrame 组件：

```tsx
// App.tsx 或其他页面组件
import ChatFrame from './components/ChatFrame';

function App() {
  return (
    <div className="app-container">
      <h1>我的主应用</h1>
      
      {/* 内联模式 */}
      <ChatFrame position="inline" height={600} />
      
      {/* 或浮动模式 */}
      <ChatFrame position="floating" height={450} />
    </div>
  );
}
```

2. 启动应用：

```bash
# 启动ChatGPT-Next-Web
yarn chat:dev

# 在另一个终端中启动主应用
yarn dev
```

## 优势

1. 保留ChatGPT-Next-Web的完整功能
2. 简单的集成方式，无需深度修改代码
3. 支持内联和浮动两种显示模式
4. 清晰的项目结构，便于后续升级和维护

## 注意事项

1. 确保端口配置正确（主应用5173，ChatGPT-Next-Web 5011）
2. 需要安装额外的依赖
3. iframe集成可能存在跨域问题，需要正确配置headers
4. 确保chatgpt-next-web目录包含完整的项目文件
